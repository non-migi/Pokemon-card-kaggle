## 良かったこと

**事前登録を最後まで崩さなかった。** 閾値を結果確認前に固定し事後に動かさなかったため、
一見有望だった5案(GR003アタッカー優先 / GR004ライン温存 / ミラー脅威拡張 / エリート加重 /
モデルsoup)をすべて実測で棄却し、提出物に入れずに済んだ。特にGR004は再生検証で
「敗戦集中度15.0倍(既定ルール14.5倍と同等)」と有望に見えたが、壁A/Bで**-4.0pt**
(この評価で唯一CIが分離した差)。規律がなければ有害な複雑さを最終提出に積んでいた。

**自分の仮説を自分で潰す検証ループ。** 「ミラーの一撃死コミットは悪手」という仮説を、
実装した本人が「勝ち試合でも同率発生(集中度0.88倍)=識別力なし」と数値で否定した。

**計器の修正。** bc_accuracy_by_typeのcid2idxオフバイワン(精度が59.9%と過小に出ていた)、
ladder_matchupsのARCHETYPE_KEYS欠落(弱点対面Lopunny/Ogerponが(other)に埋もれていた)。
どちらも放置すれば誤った判断を積み重ねる類だった。

**機構の特定を伴う敗因分析。** リプレイ精読で「計算可能な一撃死圏への主力コミット」を
13敗中12試合34局面まで定量化し、ツール(replay_log_trace.py / ohko_commit_pattern.py)も残した。

## 反省点

**1. 分解能のない測定に時間を注ぎすぎた。** 400戦A/BはCI±5ptでそれ未満の差は原理的に
判別できない — STATUSに繰り返し書いてあったのに、その帯域の実験を10本以上回した。
特にOgerpon壁の6アーム評価(全アーム勝率1〜7%の床効果)は設計段階で無意味と気づけた。
→ 教訓: **測定の前に「この設計で検出できる最小差」を計算し、狙う効果量がそれ未満なら実験しない。**

**2. ohko_guardは投資対効果が悪かった(基準率の誤り)。** 「敗戦の92%に出現」から着手したが、
**勝ち試合での出現率を先に確認すべきだった**(後の測定では集中度0.88倍=識別力なし)。
介入率0.022%のルールに1日かけ、ローカル3測定・ラダー実測とも効果を示せなかった。
→ 教訓: **「負け試合に頻出する」は「直せば勝てる」を意味しない。必ず勝ち試合の基準率と比較する。**

**3. 最大の戦略ミス: BCの構造的天井を知りながら、その内側で最適化を続けた。**
08-10時点で「学習データの重心はLB約1050、BCは模倣した集団の平均を超えられない」と記録済み。
**金は1088以上 = BC路線は完璧に実行しても届かない**という結論が締切6日前には出ていた。
それでも忠実度74%→75.6%(+1.6pt)の改善に3日を使った。
→ 教訓: **天井が既知なら、天井の内側の最適化ではなく天井を破る仮説に資源を割く。**

**4. 探索を1回の失敗で捨てた。** 本番A/B -88.4点は事実だが、その探索は
「相手行動が決定的argmax固定・価値網なし・200手ロールアウト打ち切りなし」という壊れた実装。
**「探索は有害」ではなく「この探索は有害」**が正しい結論で、価値網再構築の道を早々に閉じた。

**5. アーキタイプ転換の発見が5日遅れた。** bc_ogerponは08-10に**スパーリング相手として**作り、
その時点で我々の最強エージェントを90〜99%で粉砕していた。この信号を5日放置し、08-15に
半ば宝くじとして提出したら即座に自己最高スコア(855→862)を記録。
「デッキ×方策の共適応」の重要性は自分たちで書いていたのに系統的に探索しなかった。
→ 教訓: **壁(スパーリング相手)が自陣より強いなら、それは壁ではなく提出候補である。**

**6. 押し出し事故を2回起こした。** 07-25に「提出日時順を確認せよ」と記録したのに08-10に再発し、
最高スコア837.8を失い一時660位後退。→ 教訓: **再発した事故はチェックリスト化する。**

**7. 自分たちのドキュメントを読み返さなかった。** 「締切後2週間対戦してからLB確定」は
docs/plan.md:26に最初から書いてあったのに、私は「収束が間に合わない」と誤断して
締切3日前に「これ以上提出しない」と決定しかけた。気づいた後は試験提出を連発でき、
最良の提出(v6.0o)もその産物。→ 教訓: **重要な判断の前に自分の計画書を読み直す。**

**8. 監視のオーバーヘッド。** 60分ごとの定期更新はほぼ一度も判断を変えなかった。
異常時のみ報告で十分だった。

## 金・上位を狙うなら何が必要だったか

226点の差は運や詰めの甘さではなく**路線の差**。埋めるには次のどれかが必要だった:

- **教師を超える仕組み(ExIt/自己対戦)**: 59,249判断まで作って「完走12日」で停止した。
  7月上旬に本腰を入れていれば間に合った。BCの1050天井を破る唯一の正攻法。
- **機能する探索**: (a)相手方策の分岐も探索する (b)価値網でロールアウトを打ち切る、の2点を
  直した上での再挑戦。上位陣が何らかの先読みを持っている可能性は高い。
- **デッキ×方策の共適応の早期総当たり**: bc_kang / bc_dragapult / bc_ogerponのデータは
  7月時点で作れた。実ラダーで回していればOgerpon級の当たりを早く引け、収束時間も稼げた。

**総括: 「正しく測る技術」は身についたが、「測る対象の選び方」で負けた。**
プロセスの規律(事前登録・反証・記録)は次に持ち越せる資産なので、
次回はその規律を**天井を破る仮説の検証**に向ける。
