```

- 判定: 採用/棄却
```

## 2026-07-09 ヒューリスティックv1(ベースライン確立)

- 構成: 優先度ベース(進化900 > エネ付与800(バトル場+50) > プレイ700 > 特性600 > ワザ500+dmg/10 > 逃げる50 > END 0)。ワザ=最大ダメージ、YES/NO=原則YES、数=最大、カード選択=汎用価値スコア(ポケモン=HP+ex40/MEX60、サポート90、グッズ80、エネ60)
- 結果: vs random 200戦 91.0% [86.2–94.2] / vs first 200戦 41.0% [34.4–47.9]
- 所見: firstに負け越し。敗因の主流は両者とも「バトル場に出せるポケモン無し」(サンプルデッキがポケモン薄のミラー戦)

## 2026-07-09 アブレーションA: 自発的な「逃げる」を禁止

- 仮説: 逃げるはエネルギーを失うだけで盤面が改善しない
- 変更: RETREATスコア 50 → -10(ENDより下)
- 結果: vs first 300戦 50.7% [45.0–56.3](ベースライン41.0%)
- 判定: **採用**(+9.7pt)

## 2026-07-09 アブレーションB: ワザ選択を先頭(低コスト)に

- 結果: vs first 300戦 45.3% [39.8–51.0](A適用比 -5.4pt)
- 判定: **棄却**(最大ダメージ選択が正しい)

## 2026-07-09 アブレーションC: 効果発動(ACTIVATE)にNO

## 2026-07-09 探索APIの速度計測(プロトタイプ)

- `search_begin` 0.9ms / `search_step` 0.16ms / **終局までのフルロールアウト 8ms**(平均85手)
- 帰結: 持ち時間600秒なら1手1秒で約100ロールアウト可能 → 途中打ち切り+盤面評価関数ではなく**終局勝敗を直接価値に使える**(ドメイン知識不要で頑健)

## 2026-07-09 v2.0: 決定化フラットモンテカルロ探索

- 構成: 世界をKサンプル(自分=デッキリスト既知から可視分を除去、相手=ミラー仮定)→ 各候補手を共通世界で展開(分散低減)→ ヒューリスティック両者プレイで終局までロールアウト → 平均勝率最大の手
- 探索対象: MAIN / ATTACK / 単数CARD選択(候補>16はヒューリスティック上位に絞る)。他はヒューリスティック
- 時間管理: 1手予算 = min(2.0s, 残り時間ベース)、予備90秒、探索不能時はv1.1へフォールバック
- 結果(vs v1.1 直接対決):
  - 予算0.5s: 300戦 56.7% [51.0–62.2]
  - **予算2.0s(本番): 100戦 68.0% [58.3–76.3]** — 予算増で単調に強くなる
  - vs first 66.0% [56.3–74.5](v1.1は50%)/ vs random 93%
- 判定: **採用・提出**(#3提出、レート反映待ち)
