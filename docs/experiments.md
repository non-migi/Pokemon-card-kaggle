## 2026-07-12 multi-select対応(推論時top-N)が有意 — fieldの穴埋め

人間レビュー#3で確定した「複数選択の穴」を推論時に埋めた:
- `policy.choose` を拡張: 複数選択で各optionをスコア→ちょうどN(データの50%)は上位N、
  「N個まで」は必須min+平均超えを任意枠でmaxまで(単数学習モデルのスコアは相対順位のみ有効なので絶対でなく平均を相対閾値に)
- 事前検証(既存bc_v2, 4000決定): 無効手0件。勝者との一致=**完全一致44.3% / Jaccard0.675**(単数top-1=62.5%)
  → 単数学習モデルのスコアが複数選択にも転移する
- **A/B(v3.3g=複数選択ON vs v3.2g=OFF=ヒューリスティック丸投げ、bc_v2同デッキ): 300戦 56.2% [50.5–61.7] 有意**

意味: multi-selectは首位級(壁ボット=手書きルールで対応、#1コンボ型=必須)に対する**我々の遅れ**だった。
これを学習+探索でデッキ非依存に埋めた。**再学習不要で既存モデルのまま効いた**(スコアが転移するため)。
複数選択は全決定の5.4%だが数%の勝率に効く。次: multi-select訓練データを入れた再学習で「何個選ぶか」の閾値を較正(Increment 2)。
