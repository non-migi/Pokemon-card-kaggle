# 自分が使うデッキの勝者を模倣する: PTCG AI Battle Challenge における「デッキ×方策の共適応」

**副題:** ポケカ経験の乏しい単独参加者がAIコーディングエージェントと組み、150KBの模倣学習方策で 429位 / 6,807チーム(レート905.8)に到達した方法と、締切後に各提出が1,000戦を戦った収束データが語ること。

**トラック:** Strategy Category · Simulation結果: 6,807チーム中429位、最終レート905.8(銅圏。銀ライン924.0)

> これは提出用英語本文 `writeup_en.md` のレビュー用対訳です。提出は英語版のみ。

## 1. 要約

最終エージェントは Teal Mask Ogerpon ex デッキを、公式「Daily Top」リプレイのうち**同じデッキを使った勝者側の判断だけ**で学習した純粋な模倣学習(BC)方策で操作する。推論はnumpyの2タワーランカーで、各合法手を1ミリ秒未満で採点する。1試合あたりの思考時間の中央値は600秒予算のうち3秒だった。最終2枠のもう1本は、同じ手順で作ったGrimmsnarl exエージェントである。

設計を決めた発見は3つで、いずれも事前登録したA/Bテストか本番ラダー実験で確定した。

1. **BC方策は学習したデッキでしか強くない。** デッキと方策はペアで選ばなければならない。
2. **BCの上に決定化探索を載せると本番で悪化した**(同一デッキ・同一モデルで −88点)。
3. **レートを失うのは主戦場ではなく、分布外の相手の長い裾である。** これは学習データを日次で更新し、新カードを語彙に入れることで直る。

締切後に各提出約1,000戦を戦った収束(図1)と、同一ビルドの独立再走行(Ogerpon 905.8 / 902.8、Grimmsnarl 843.6 / 834.6)は、このレートが再現可能であり幸運な引きではないことを示す。

## 2. 問題の枠組み

環境の3つの性質が、それ以降の全てを決めた。

- **隠れ情報と長い地平線。** 1試合は片側約140判断(中央値10ターン)。1手は型付きの可変集合の合法手(プレイ、エネ付け、進化、特性、攻撃、逃げ、複数選択のサーチ)から選ぶ。
- **レートは収束する。** ラダーは600始まりのガウス型レーティングで同格マッチング。序盤のスコアはノイズで、我々の最初のAlakazamエージェントは78戦で920.7、315戦で795.7だった。したがって80〜100戦未満では提出を判断せず、締切後のレートの振る舞いも測った(図1)。
- **チームスコアは最新2提出のmax。** これにより、相関のないペア(専門型+万能型)は最も安全なエージェントを2本並べるより価値が高い。

## 3. アプローチとその変遷

### 3.1 探索から模倣へ

手書きのヒューリスティックと決定化フラットモンテカルロ探索(隠れカードをサンプルしヒューリスティックでロールアウト)から始めた。750付近で頭打ちになった。突破口は公式リプレイからの模倣学習で、Daily Topエピソードの**勝者側**の `(観測, 選んだ手)` ペアを全て抽出してランカーを学習した。

**モデル**(図6)。状態タワー(94特徴: 両者の手札・ベンチ・サイド・エネルギー・山札と捨て札の枚数・プロンプト種別とターン文脈)とオプションタワー(48特徴: 手の種別、領域、カード種別、技コスト/ダメージ、対象HP、および16次元の学習カード埋め込み)がそれぞれ128ユニットの隠れ層に写像され、内積がロジットとなり、合法手上のsoftmaxを交差エントロピーで学習する。複数選択はtop-Nで扱う。書き出した重みは150KBでnumpyで動くため、タイムアウトとは無縁である。

**制約は忠実度である。** モデル系列(図5)でholdout top-1精度は70.3%から75.6%に上がった。データ日数の追加、カード語彙の拡張、エポック7以降で学習率を半減する12エポックの日程の採用による。最終Grimmsnarlモデルは同一デッキのミラーで13日版の前身に 56.9% / 400 [52.0–61.6] で勝ち、日次更新で初めて信頼区間が50%を離れた。

### 3.2 デッキ×方策の共適応(中心的主張)

Alakazam学習の方策で操作した最初のGrimmsnarl提出は751で凍結し、Grimmsnarl学習の方策で操作したGrimmsnarlデッキは840に達した。ローカルでは、Alakazam方策で他デッキを操作すると弱い壁には88.9%勝つのに実際の相手には25.7%だった。教訓は一般化した。**BC方策は1つのデッキのための方策**である。だから我々が作った全てのスパーリング相手「壁」はそのデッキの勝者で学習した(デッキ, 方策)ペアであり、デッキの選択は「どのアーキタイプの勝者を最もよく模倣でき、我々がマッチされる帯で誰に勝てるか」で決めた。

### 3.3 探索は害になる: 本番A/Bテスト

同一デッキ・同一の`bc_grim2`重みで、BC top-5を8秒の決定化探索で並べ替えるか否かだけが違う2提出を並走させた。210戦と158戦の後、純BCは840.0、探索版は751.6だった(図4)。ローカルの壁の結果(67.1% 対 46.0%)と符号が一致する。診断: 世界は隠れカードだけをサンプルし、相手モデルは決定的argmaxだったため、各世界は終局まで一本道になる。価値網が無いので140手のロールアウトが方策誤差を複利で積む。ロールアウトのsoftmax温度(0.5 / 1.0)は悪化させ(50.0% / 34.3%)、AUC 0.851の価値網もA/Bに負けた(47.8% / 400)。純BCを出荷した。

### 3.4 レートを失うのは長い裾

210戦時点でGrimmsnarlエージェントは主戦場で勝っていた(ミラー55.7%、Alakazam 58.5%)のに総合50%だった。原因は十数種の珍しいデッキとの26戦が3勝23敗だったこと。143枚の語彙が相手の43枚(うち41枚がポケモン)を「未知」索引に潰していたため、方策は文字どおりそれらを見ることができなかった。20日分のリプレイで作り直すと語彙は211になり、同じバケットは65%まで回復した(図2右)。したがってデータの日次更新は嗜みではなく、**止めると新しいデッキが見えなくなる。**

### 3.5 明示的ガードと、それを有効のままにした理由

LopunnyとOgerponに対する全敗戦を読むと、13敗中12敗で、相手の見えているエネルギーから計算できる一撃死圏へ主要ポケモンを昇格または進化させていた。そうした選択肢をBCのargmaxの前に拒否する2ルール(GR001 昇格/入替、GR002 進化)を追加した。事前登録した検定は判定不能(床効果下でΔ +0.25 / −1.50 / −4.25pt、介入率0.022%)で、同じパターンは勝ち試合でも同率で起きたため、「無害としてのみ生き残った仮説」として報告する。さらに2ルール(アタッカー優先、進化ライン温存)は反証され(−4.0pt)、無効にしてある。

### 3.6 アーキタイプ転換

公式Daily Topを追跡すると(図7)、Grimmsnarlの勝者チームシェアは 33.6% → 62.7% → 41.9% と動き、Teal Mask Ogerponは0%から約9〜12%に伸びた。86チームの勝者判断39.1万件で`bc_ogerpon`を**スパーリング相手として**学習したところ、6アーム×400戦で我々の最強Grimmsnarlエージェント群に90〜99%で勝った。8月15日にラダー試験として提出すると35勝19敗(64.8%)で当時の自己最高レートに達した。これが最終1枠目になった。

## 4. 一貫性と頑健性の証拠

**再現性。** 同一ビルドを600から再提出すると同じ近傍に収束した。Ogerpon 905.8と902.8、Grimmsnarl 843.6と834.6。図1は締切後15日間の両最終提出を示す。最初の50戦では±100の振れ、その後は相手プール自体が再整列する中で約70点の帯に収まり、2エージェントの順序は終始安定していた。

**対面プロファイルの正直な開示**(図2、各1,000戦)。Ogerponエージェントは専門型である。Grimmsnarlに89.6%(n=394、全体の39%)、Garchompに76%、珍しいデッキに59%だが、Alakazamに30%、Lopunnyに12%、Kangaskhanミルに9%。Grimmsnarlエージェントは万能型で、Alakazam 60%、Archaludon 72%、Dragapult 67%、珍しいデッキ65%、ミラー51%、唯一の穴がOgerpon(12%)。ペアは意図的に逆相関で、互いの最悪対面を補う。

**専門型が高得点だった理由。** 850〜950のレート帯は我々の標本で約40%がGrimmsnarlだったので、その区画での90%の優位が他の40%未満を上回る。これはメタゲームへの賭けであって普遍的な強さの主張ではなく、だからこそもう1枠に万能型を残した。Kangaskhanミル対面(43敗中23敗が自山切れ)が最も明確な残課題で、模倣元の勝者がこの対面をほとんど経験していないため、方策はドローの節約を学んでいない。

**時間と障害に対する安定性。** 最終2,000戦で1試合600秒予算のうち中央値3秒・最大9秒、タイムアウトなし。ランタイムの各層は例外時に次の層へフォールバックする(図6)。

## 5. デッキコンセプト(図8、CSV添付)

**デッキA — Teal Mask Ogerpon ex(最終1枠目)。** Ogerponを4枚採用した勝者86チームの最頻60枚。Ogerpon ex 4、基本草エネルギー18、Grow Grass Energy 2、エンジンとして Bug Catching Set ×4、Energy Search ×4、Energy Retrieval ×2、Judge ×4、Lillie's Determination ×4、Boss's Orders ×3、Lively Stadium ×2。プランは一点集中で、Ogerponの特性が毎ターン手札から草エネルギーを付けて1枚引き、Myriad Leaf Showerは両バトルポケモンに付いたエネルギー1枚につき30を加算するため、全てのトレーナーズはエネルギーを探すか、回収するか、加速しながら相手の手札を妨害する。「4枚以上」フィルタが重要だった。素朴な「Ogerponを含む」検索はOgerponを1枚差ししたKangaskhan/Crustleミルデッキを大量に拾い、誤った方策を学習していたはずである。Grimmsnarlに対しては構造的な優位がある。Grimmsnarl exのPunk Upは最大5枚の悪エネルギーを一気に場に置くが、相手バトルポケモンのエネルギー1枚ごとに我々の攻撃が30増えるので、210HPのたねアタッカーはStage 2デッキを強くしている加速そのものを罰する。89.6%はそれを反映している。

**デッキB — Marnie's Grimmsnarl ex / Froslass(最終2枠目)。** 7月23日時点のTop-8 Grimmsnarlチームの合意リスト(Grimmsnarl使用111チーム中82チームが同一の60枚)。Impidimp/Morgrem/Grimmsnarl ex 4-3-3、Munkidori 4、Snorunt/Froslass 2-2、Spikemuth Gym ×4、Rare Candy ×3、Buddy-Buddy Poffin ×4、Poké Pad ×4、Petrel ×4。プランはRare Candyで早期進化し、Punk Upで悪エネルギー5枚を一度に持ってきて、FroslassのFreezing ShroudでダメカンをばらまきMunkidoriで移し、320HPの体からShadow Bullet(180+ベンチに30)で締める。より速いエネルギー加算型アタッカー以外に悪い対面がなく、これが幅広いが派手さのないプロファイルを説明する。

**デッキの選び方。** 薄い我々のカード知識ではなく、(a)目標帯での勝者チームシェア、(b)その正確なリストに対するクリーンな学習データの量、(c)自陣最強エージェントに対するローカル壁の結果で選んだ。デッキリストは方策と一緒に凍結し、再学習なしにカードを1枚も変えなかった。

## 6. 次にやるなら変えること

- **BCの天井は教師の水準にある。** 学習データの重心はレート約1,050で、金には1,131が必要だった。我々は最後の数日をその天井の内側で忠実度を1.6pt上げることに使った。その上に行く道はExpert Iterationか自己対戦(蒸留判断5.9万件まで作って停止した)だった。
- **自分に勝つ壁は壁ではなく候補である。** Ogerpon方策は提出の5日前に自陣最強を圧倒していた。
- **31戦で行動しない。** 事前登録した「650未満なら差し替え」規則が31戦で発動し、結果的に最良となるエージェントを外すところだった。人間が覆し、そのビルドは後に905.8に達した。
- **設計が解像できるものだけを測る。** 400戦A/Bの区間は±5ptで、2ptの効果を区別できない実験を回しすぎた。

## 7. 再現性

コード、エージェント定義、学習メタデータ付きモデルレジストリ、全A/B結果(`results/arena.jsonl`)、実験ログ全文をリンク先リポジトリでMITのもと公開している。`python -m ptcglab.build v6.0o` で提出物そのものを再構築でき、`scripts/bc_extract.py → bc_filter_deck.py --key Ogerpon --min-copies 4 → train_bc.py` でモデルを再現できる。コンペ配布データとシミュレータは再配布していない。
