## 推奨: ARC-AGI-3(詳細は `arc-agi-3.md`)

**理由1: 今回身につけた能力がそのまま使える。**
隠れた状態を持つゲーム環境を探索し、複数手先を読んで行動するエージェントを書く競技。
64×64・値0〜15のグリッドを frame として受け取り、`RESET` と `ACTION1`〜`ACTION6`(座標指定)を返す。
レベル制で `NOT_FINISHED` / `WIN` / `GAME_OVER` を遷移する。
PTCGでやった「観測→合法手の採点→行動」のカスケードと、アリーナによる評価基盤がそのまま流用できる。

**理由2: 金がかからない。** Notebook提出のみで、**Kaggleが計算資源を出す**(GPU 9時間以内、ネット遮断)。
手元のGPUは不要。1万円の予算制約が効かない唯一のカテゴリ。

**理由3: 銅の絶対水準が低い。** 1位18.81 / 中央値 **0.29** / 銅 **3.51**(満点100)。
低スコア勢は提出回数の中央値が**2回**(36%は1回だけ)で、大半は離脱組。
⚠️ ただし09-19の追加調査で、**同一コードでもLBが2.5〜5.5に振れる**ことが判明した。
銅3.51はこの揺れ幅の内側にあり、**実力より試行回数で取るメダル**になる。
詳細と根拠は `arc-agi-3.md` §6.1。

# 🔴 09-21 再走査: Kaggriculture が「今回と同じ形式」だった(紹介不足の訂正)

前回「農業(CSV提出)」と書いたのは誤り。**Kaggriculture は Pokemon TCG とまったく同じ
エージェント対戦シミュレーション**だった。構造がここまで一致している。

| 仕様 | Pokemon TCG | Kaggriculture |
|---|---|---|
| 提出物 | エージェント(bot) | 同じ |
| 評価 | スキルレーティングのラダー、同格マッチング | 同じ |
| 最終評価 | **最新2提出のみ** | **同じ** |
| 提出上限 | 5回/日 | 同じ |
| 締切後 | 約2週間対戦を継続して収束 | **10-01〜10-15に継続、収束後に確定** |
| 提出時検証 | 両席ロード検証 | **自己対戦のValidation Episode** |
| 公式データ | Daily Top Episodes | **Daily Top Episodes Dataset(20GiB、44日分)** |

**`docs/playbook.md` §1 に書いた構造的教訓が、1つ残らずそのまま当てはまる。**

## ゲーム内容
2人のプレイヤーが別々の農場を持ち、**30日シーズン(720ターン)で利益を競う**ターン制ゲーム。
作物の植付け・水やり・施肥・収穫、家畜の購入と世話(卵・牛乳・羊毛)、肥料の回収と利用、
隣接区画の購入による農場拡張、そして**売却量に価格が反応する動的市場での取引**。
勝敗は720ターン終了時点の所持コイン。

## 🎯 最重要の発見: BCの天井がメダル圏にある
公式 Daily Top Episodes Dataset の**平均スコアの中央値は 2,735〜3,080**(参加者 Georgy Mamarin の分析)。
`playbook.md` §3.3 の「**BCの天井は模倣した集団の平均**」をそのまま当てはめると、

> このデータを模倣した方策の天井 ≒ **2,700〜3,000 = 銀〜金圏**

Pokemon TCG では教師の重心がレート1050で金1131に届かなかったが、
**ここでは教師の重心がそのまま金ライン(2,908)付近にある**。
つまり**我々の実証済みパイプライン(bc_extract → bc_filter → train_bc)が、
そのまま銀圏に届く設計になっている**。

参加者の証言も一致する:
- 「Really useful dataset for imitation learning and behavior cloning」(Noberto Frota)
- 銀メダル到達者 Snorlax: 「BCデータは公式のtop-match replay集を使えばいい」
- 一方で「純RLはこの環境に向かない」との声が複数(AMMの価格曲線と720ステップの長期地平が厳しい)
