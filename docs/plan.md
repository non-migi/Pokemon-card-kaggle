## 前提となる確定事実(公式ページ・実測で裏取り済み)

### コンペ構造
- **Strategy部門の提出物はKaggle Writeup(2000語)のみ**。審査: Model Score 70%(手法+トラック内パフォーマンス)/ Deck Score 20% / Report Score 10%。審査期間9/14〜10/11
- SimulationのLB成績がWriteupの「パフォーマンスの証拠」になる

### ラダー仕様(2026-07-11実測確認)
- 対戦数は無制限(自動で回り続ける)。新提出ほど高頻度(初日35〜60戦)
- ガウスレーティング(μ0=600)。同格マッチング。**レートは平衡値(真の実力)に収束する** — 早期の好成績は持ち越されない
- **最終評価は「最新2提出」のみ**。3番目以降は対戦停止・レート凍結(実測で確認)
- 締切後さらに約2週間対戦してからLB確定 → 締切直前提出でも収束には十分
- レート判定に必要な戦数: **80〜100戦(約2日)**。10戦未満は完全にノイズ

### 環境(レート帯別デッキ遭遇率、07-11集計)
| 帯 | 特徴 |
|---|---|
| 550-700(現在地) | 雑多。ルカリオ型12%・フーディン型18%・初期デッキ系12% |
| 700-850 | その他40%・ルカリオ20% |
| 850-1000 | ブリジュラス45%(要追加サンプル)・フーディン25% |
| **1000+** | **フーディン型51.7%**・オーロンゲ17% |

**→ トップ帯進出の必要十分条件はほぼ「対フーディン型で勝ち越すこと」**(現状の対フーディン勝率20%)。
レートは平衡収束するため「登る途中の帯」への最適化は不要。目標帯(850+)にだけ最適化する。

### 確定した技術知見(experiments.md詳細)
- 有効: 決定化フラットMC探索 / メタデッキ照合belief / 探索予算スケーリング(0.5s→2.0sで+11pt)
- 棄却: MCTS(※ハーネスバグで要再検証)/ 価値関数v0(LR・AUC0.73はフルロールアウト8msに勝てない)/ H4サイド考慮 / 進化的デッキ最適化(局所解)
- デッキ×プレイヤー共適応: LB王者デッキはうちのAIでは操縦不能(総当たり最下位)。デッキ選択はプレイヤーの質とセット

## リスクと対策

- **対フーディンが崩せない**: G2失敗時は「使う側に回る」転換路線を用意済み(学習方策)

- **メタシフト**: 週次収集で追随。beliefライブラリ更新は数分

- **提出事故**: 500エラー/認証失効の経験あり → 最終提出は8/14までのバッファ運用
