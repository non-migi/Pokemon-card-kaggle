# ポケカ学習ガイド(指示者用・最短ルート)

目的: AIの実験結果を読んで意思決定できる「読解力」を最短で身につける。
カード暗記は不要。ここにある材料はすべてリポジトリ内のデータ・実対戦ログから生成した。

## 1. リプレイを見る(効果大・まず2〜3戦)

### 見方A: 日本語ビューア(推奨・準備済み)

`replays/epXXXX_jp.html` をブラウザで開く。**日本語カード名・HPバー・日本語イベントログ付き**で、
カードをクリックすると**ワザ・特性・トレーナーズ効果の日本語テキスト**がポップアップする。
両者の手札・サイドまで見える全情報視点(学習用)。←→キーで手番を進める。

| ファイル | 見どころ |
|---|---|
| `ep85047638_jp.html` | 18手で敗北。序盤の事故(たね不足/セットアップ失敗)の典型を確認 |
| `ep85033439_jp.html` | 長期戦の末に負け。リソース管理・サイドレースのどこで差がついたか |
| `ep85063903_jp.html` | 中期戦 |
| `ep85171678_jp.html` | 長期戦 |
| `ep85027844_jp.html` | 中盤で崩れたケース |

追加生成は1コマンド: `.venv/bin/python scripts/render_replay_jp.py <エピソードID>`
(「勝ち試合も出して」「vsフーディン型だけ出して」と言ってくれてもすぐ出せる。52敗分キャッシュ済み)

※ 同名の `_loss_....html` は公式ビューア(英語)版。日本語版で足りればそちらは無視してよい。

### 見方B: Kaggleサイト上

リーダーボードの各エピソードはブラウザで再生できる:
`https://www.kaggle.com/competitions/pokemon-tcg-ai-battle/leaderboard` → 自チームの行 → エピソード一覧

### 見るときのチェックリスト(違和感センサー)

- [ ] 最初の数ターン: ベンチにポケモンを並べているか(枯れて負けるのが敗因1位)
- [ ] エネルギーを毎ターン貼れているか。誰に貼っているか(次のアタッカーに前貼りしているか)
- [ ] 「逃げる」べき場面(バトル場が瀕死・技が撃てない)で棒立ちしていないか
- [ ] 相手のexを倒せる場面でスルーしていないか(=サイド2枚の好機)
- [ ] サポート(1ターン1枚)を毎ターン使えているか
- **違和感を見つけたら、そのままの言葉で私に伝える**(例:「40手目で逃げないのは変」)→ こちらで仮説→A/B実験に変換する

## 2. サイドトレードの概念(1〜2時間で身につく最重要理論)

### ルール
- 勝利条件: 相手のポケモンを倒して**サイドを6枚**取り切る(他に山札切れ・場のポケモン全滅でも決着)
- 倒したポケモンごとに取れるサイド: **通常=1枚 / ex=2枚 / メガex=3枚**

### 帰結: 「何で戦うか」が交換レートを決める

- 通常ポケモンだけで戦う側は6回倒される必要があるが、メガexで戦う側は**2回**倒されたら終わり
- つまり「HP350のメガexは強い」は半分嘘 — **倒されたときの損失もHPの一部**
- 例(うちのデッキ): メガユキノオーex(HP350)が2回倒される=サイド6枚=敗北。相手が通常ポケモンで戦っているなら、こちらは6体倒す必要がある

### LB王者・フーディン型が強い本当の理由がこれ

フーディン(HP140・**通常ポケモン=取られるサイド1枚**)が200点級の火力を出す。
相手のex/メガは1〜2回の攻撃で沈むのに、フーディン側は6体倒されるまで負けない。
**火力とサイドレートの両取り**が王者の正体(仕組みは次章)。

### 議論で使える言葉
- 「この交換はサイドレートが悪い」= exで通常ポケモンを殴り合うような損な交換
- 「サイドプラン」= 6枚をどの組み合わせで取るか(2+2+2か、1×6か)

## 3. 上位アーキタイプ3種の勝ち筋(実カードテキストから解説)

### ① フーディン型 — LB王者(上位7チーム使用、勝率67%)

構成: ケーシィ→ユンゲラー→**フーディン** / ノコッチ→**ノココッチ** / キチキギスex / シェイミ

**勝ち筋: ドロー特性を連鎖させて手札を貯め、フーディンの「ハンドパワー」で一撃**

- ユンゲラー/フーディンの特性**「サイコドロー」**: 手札から出して進化させたとき、山札を2枚/3枚引く
- ノココッチの特性**「にげあしドロー」**: 山札を3枚引き、その後**自分ごと山札に戻る** — 戻るのでまた進化でき、何度でも使い回せるドローエンジン
- フーディンのワザ**「ハンドパワー」**(超1個): **自分の手札の枚数×2個のダメカン**を相手バトルポケモンにのせる。手札10枚なら200ダメージ相当
- シェイミの特性**「はなのカーテン」**: ルールを持たないベンチポケモン全員はワザのダメージを受けない(盤面が崩れない)
- キチキギスexの特性**「さかてにとる」**: 前の相手の番に自分のポケモンが倒されていたら3枚引く(**倒されるほど手札が増えて火力が上がる**)

**なぜうちのAIには使えないか**: 強さの源が「特性の多段連携」と「手札を貯めてから撃つ遅延価値」にあり、
1手ごとの貪欲な評価では測れない。
**対策のヒント**: シェイミで守れない「ルールを持つポケモン」への狙撃、手札が貯まる前の速攻。

### ② マリィのオーロンゲ型(勝率64%)

構成: マリィのベロバー→ギモー→**マリィのオーロンゲex** / マシマシラ / ユキメノコ

**勝ち筋: 進化しただけでエネ全開+320HPの高耐久で殴り続ける**

- オーロンゲexの特性**「パンクアップ」**: 進化したとき山札から**基本悪エネルギーを5枚まで**「マリィのポケモン」に好きなように付ける(1回の進化でエネ問題がほぼ解決する)
- ワザ**「シャドーバレット」**(悪2個): **180ダメージ+ベンチ1匹に30**。2エネで180は破格のコスパ
- マシマシラの特性**「アドレナブレイン」**: 自分のポケモンのダメカン3個を相手に**のせ替える**(回復と攻撃を同時に、毎ターン)
- ユキメノコの特性**「いてつくとばり」**: ポケモンチェックのたび**特性持ち全員にダメカン1個**
  — 特性だらけのフーディン型への強烈なメタ

### ③ メガガルーラ型(勝率53-57%)

構成: **メガガルーラex** / イシズマイ→**イワパレス** / シェイミ

**勝ち筋: ドローしながら殴れる300HP+「ex攻撃を完全無効化する壁」の2枚看板**

- メガガルーラexの特性**「おつかいダッシュ」**: バトル場にいるだけで毎ターン山札を2枚引く(殴りながら手札が回る)
- ワザ**「マシンガンコンボ」**(無3個): 200+ウラが出るまでコインを投げてオモテ×50追加(期待値約250)
- イワパレスの特性**「しんぴのいしやど」**: **相手の「ポケモンex」からワザのダメージを受けない**
  — ex主体のデッキはイワパレス1匹をどうやっても突破できない
- イシズマイのワザ「かくせい」: 山札から自力で進化(エネ1個)
- 弱点: メガガルーラexは倒されると**サイドを3枚**取られる(2回倒されたら敗北)

### 三すくみ構造(現メタの読み)

- **フーディン型**(ほぼ通常ポケモン軍団)は、ex主体デッキに**サイドレート**で勝つ(相手は6体倒す必要、こちらは2〜3体でよい)
- **ユキメノコ入りオーロンゲ型**は、特性に依存しきったフーディン型を「いてつくとばり」で毎ターン削って勝つ
- **イワパレス**はexだらけのデッキを完封するが、フーディン(非ex)には壁として機能しない
- **うちのサンプルデッキ**(メガユキノオーex+水エネ35枚)はどれとも違う「エネルギー物量」型。
  カイオーガの**「ぎゃくりゅう」**(水1個: トラッシュの水エネ×20ダメージ)とメガユキノオーexの**「アバランチハンマー」**(水2個: 山札上6枚をトラッシュしその中の水エネ×100)が、エネ35枚という異常な構成と噛み合う。「うずまくなみ」やきぜつでトラッシュに落ちたエネが全部「ぎゃくりゅう」の弾になる
