目的: AIの実験結果を読んで意思決定できる「読解力」を最短で身につける。
カード暗記は不要。ここにある材料はすべてリポジトリ内のデータ・実対戦ログから生成した。

## 1. リプレイを見る(効果大・まず2〜3戦)

### 見方A: 日本語ビューア(推奨・準備済み)

`replays/epXXXX_jp.html` をブラウザで開く。**日本語カード名・HPバー・日本語イベントログ付き**で、
カードをクリックすると**ワザ・特性・トレーナーズ効果の日本語テキスト**がポップアップする。
両者の手札・サイドまで見える全情報視点(学習用)。←→キーで手番を進める。

| ファイル | 見どころ |
|---|---|
| `ep85047638_jp.html` | 18手で敗北。序盤の事故(たね不足/セットアップ失敗)の典型を確認 |
| `ep85033439_jp.html` | 長期戦の末に負け。リソース管理・サイドレースのどこで差がついたか |
| `ep85063903_jp.html` | 中期戦 |
| `ep85171678_jp.html` | 長期戦 |
| `ep85027844_jp.html` | 中盤で崩れたケース |

追加生成は1コマンド: `.venv/bin/python scripts/render_replay_jp.py <エピソードID>`
(「勝ち試合も出して」「vs Alakazam型だけ出して」と言ってくれてもすぐ出せる。52敗分キャッシュ済み)

※ 同名の `_loss_....html` は公式ビューア(英語)版。日本語版で足りればそちらは無視してよい。

### 見方B: Kaggleサイト上

リーダーボードの各エピソードはブラウザで再生できる:
`https://www.kaggle.com/competitions/pokemon-tcg-ai-battle/leaderboard` → 自チームの行 → エピソード一覧

### 見るときのチェックリスト(違和感センサー)

- [ ] 最初の数ターン: ベンチにポケモンを並べているか(枯れて負けるのが敗因1位)
- [ ] エネルギーを毎ターン貼れているか。誰に貼っているか(次のアタッカーに前貼りしているか)
- [ ] 「逃げる」べき場面(バトル場が瀕死・技が撃てない)で棒立ちしていないか
- [ ] 相手のexを倒せる場面でスルーしていないか(=サイド2枚の好機)
- [ ] サポート(1ターン1枚)を毎ターン使えているか
- **違和感を見つけたら、そのままの言葉で私に伝える**(例:「40手目で逃げないのは変」)→ こちらで仮説→A/B実験に変換する

## 2. サイドトレードの概念(1〜2時間で身につく最重要理論)

### ルール
- 勝利条件: 相手のポケモンを倒して**サイドを6枚**取り切る(他に山札切れ・場のポケモン全滅でも決着)
- 倒したポケモンごとに取れるサイド: **通常=1枚 / ex=2枚 / メガex=3枚**

### 帰結: 「何で戦うか」が交換レートを決める

- 通常ポケモンだけで戦う側は6回倒される必要があるが、メガexで戦う側は**2回**倒されたら終わり
- つまり「HP350のメガexは強い」は半分嘘 — **倒されたときの損失もHPの一部**
- 例(うちのデッキ): Mega Abomasnow ex(HP350)が2回倒される=サイド6枚=敗北。相手が通常ポケモンで戦っているなら、こちらは6体倒す必要がある

### LB王者・Alakazam型が強い本当の理由がこれ

Alakazam(HP140・**通常ポケモン=取られるサイド1枚**)が200点級の火力を出す。
相手のex/メガは1〜2回の攻撃で沈むのに、Alakazam側は6体倒されるまで負けない。
**火力とサイドレートの両取り**が王者の正体(仕組みは次章)。

### 議論で使える言葉
- 「この交換はサイドレートが悪い」= exで通常ポケモンを殴り合うような損な交換
- 「サイドプラン」= 6枚をどの組み合わせで取るか(2+2+2か、1×6か)

## 3. 上位アーキタイプ3種の勝ち筋(実カードテキストから解説)

### ① Alakazam型 — LB王者(上位7チーム使用、勝率67%)

構成: Abra→Kadabra→Alakazam / Dunsparce→Dudunsparce / Fezandipiti ex / Shaymin

**勝ち筋 = 手札を無限に増やして「手札枚数×20ダメージ」で殴る**
- Kadabra/Alakazamの特性 Psychic Draw: 進化時にドロー
- Dudunsparceの特性 Run Away Draw: **3枚引いて山札に戻る**(何度も使い回せるドローエンジン)
- 手札10枚なら Alakazam「Powerful Hand」= ダメカン20個(**200ダメージ相当・エネ1個**)
- Shaymin特性 Flower Curtain: ルールボックス無しのベンチを攻撃から守る(盤面が崩れない)
- Fezandipiti ex特性: 前の相手ターンに倒されていたら追加ドロー(倒されるほど回る)

**なぜうちのAIには使えないか**: 価値が「ドロー特性の多段連携」にあり、1手ごとの貪欲評価では
Powerful Handの遅延価値(手札を貯めてから撃つ)を測れない。
**対策のヒント**: ベンチ狙撃(Shaymin貫通)や、手札が貯まる前の速攻。

### ② Grimmsnarl型(勝率64%)

構成: Marnie's Impidimp→Morgrem→Grimmsnarl ex / Munkidori / Froslass

**勝ち筋 = 高耐久ex(320HP)+2エネ180点の高効率+ダメカン操作**
- Grimmsnarl ex「Shadow Bullet」: 2エネで180+ベンチ30(高コスパ・ベンチ狙撃)
- 特性 Punk Up: 進化時に山札から悪エネ2枚加速
- Munkidori特性: ダメカン3個を相手に移し替え(実質回復+射撃)
- Froslass特性: **特性持ち全員に毎ターンダメカン1個**(特性だらけのAlakazam型へのメタ)

### ③ Kangaskhan型(勝率53-57%)

構成: Mega Kangaskhan ex / Dwebble→Crustle / Shaymin

**勝ち筋 = ドローしながら殴る300HP + 「ex攻撃を無効化する壁」**
- Mega Kangaskhan ex特性 Run Errand: バトル場にいるだけで毎ターン2ドロー
- 「Rapid-Fire Combo」: 200+コイン表ごとに+50(期待値250)
- **Crustle特性: 相手のexポケモンからの攻撃ダメージを全て防ぐ** — ex主体デッキ相手には無敵の壁
- ただしメガex=倒されたらサイド3枚の危険と隣り合わせ

### 三すくみ構造(現メタの読み)

- Alakazam(通常ポケモン軍団)は ex主体デッキにサイドレートで勝つ
- Froslass入りGrimmsnarlは特性依存のAlakazamを毎ターン削って勝つ
- CrustleはexだらけのデッキをシャットアウトするがAlakazam(非ex)には壁にならない
- **うちのサンプルデッキ**(Mega Abomasnow+エネ35枚)はどれとも違う「エネ加速型の速攻」。
  Kyogre「Riptide」がエネ枚数×20で終盤に大火力になる
